# CVR Lost & Found — Frontend-only demo

A responsive student lost-and-found website prototype for CVR College of Engineering. It runs directly in a browser and does not connect to Firebase, a database, or any backend.

## Run it

1. Download and extract this ZIP.
2. Open the `cvr-lost-found-frontend` folder.
3. Double-click `index.html` to open it in your browser.
4. Enter any valid-looking email address and a password of at least 4 characters. For the sign-up option, enter a name too.

No installation, API key, Firebase project, or paid storage is needed.

## What's included

- Demo login and sign-up screens
- Student dashboard with example lost/found reports
- Search, category filter, and All/Lost/Found tabs
- Create reports with item details and contact information
- Photo selection with a browser-only preview (no upload)
- My Reports section, contact demo, resolve/delete actions
- Responsive layout for desktop and mobile

## Important demo limitations

- Login is a visual demo only; it does not verify college email or authenticate a real student.
- New reports exist only in the current browser tab/session and are not shared with other users or saved to a server.
- Selected photos use a temporary browser preview URL. They are not uploaded or stored by this website; the preview disappears when the page/session is closed or refreshed.
- Example reports are sample content, not real campus reports.

This is a frontend prototype, not a production service.
